# ThinkFirst 项目解析教学

这里用于后续逐章编写教学文档。下面是章节规划，正文尚未完成。

1. 项目目标与完整体验：从一句想法到需求文档。
2. 环境准备与本地运行：前后端分别如何启动。
3. Vue 页面与组件：卡片、密码显示和文档预览。
4. 一次请求如何流转：前端、接口、服务与数据库。
5. 引导流程：快速模式、逐步模式、回退与确认。
6. 接入大模型：厂商选择、上下文、格式校验和故障切换。
7. 数据持久化：历史记录、会话恢复和文档版本。
8. 密码与密钥保护：哈希、加密、鉴权与限流。
9. 文档生成与导出：框架、章节优化和轻度润色。
10. 测试与云端部署：构建、备份、更新、回滚。

每章建议采用“学习目标 → 对应代码 → 请求或数据示例 → 操作练习 → 常见错误”的结构。涉及密钥的示例仅使用占位符。
